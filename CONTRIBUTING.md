# Contributing

Thank you for improving Daily Context.

1. Keep the CLI dependency-free and compatible with Python 3.10 or newer.
2. Add or update tests for behavioral changes.
3. Preserve append-only evidence and record semantics.
4. Do not add real transcripts, credentials, personal data, or customer information.
5. Run `./scripts/test.sh` before opening a pull request.

For a format change, document compatibility and provide a migration before increasing `schema_version`.
