# Weekly synthesis

The weekly output should change next week's behavior, not merely retell the week.

1. Process pending sources and uncaptured notes.
2. Freeze the input set with `daily-context weekly`.
3. Reconcile task status, owners, waiting items, and follow-up dates.
4. Review each active goal and ensure it has a concrete next action.
5. Summarize outcomes and work products with record IDs.
6. List decisions, corrected assumptions, risks, and unresolved conflicts.
7. Reflect on what worked, what caused avoidable friction, and what should change.
8. Order next week's priorities by dependency, value, risk, or information gain. State the ordering rule.

Every specific assertion should cite a record ID. If a later correction changes the review, publish a successor or revision that names what it supersedes; do not erase the original review.
